# Portfolio Website

Website portfolio pribadi yang dibuat menggunakan HTML, CSS, dan JavaScript dan dibantu brainstorming oleh Ai (Claude dan ChatGPT)

## Tentang Website

Website ini merupakan portfolio pribadi yang berisi informasi tentang saya,
skills yang saya miliki, project yang pernah dibuat, dan informasi kontak.

## Teknologi

- HTML
- CSS
- JavaScript

## Fitur

- Responsive untuk desktop, tablet, dan mobile
- Navbar responsive
- Section Home
- About
- Skills
- Portfolio
- Contact
- Download CV
